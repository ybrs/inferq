Write a Python 3 script that reads a CSV file whose path is given as the first command-line argument. The CSV has the columns id, status, amount. Print one line per distinct status, formatted as "<status>: <count> orders, <total> total", where total is the sum of amount for that status, printed with two decimals. Sort the lines by status name. If the file has no "status" column, print an error to stderr and exit with code 1. Output only the code, no explanation, no fences.
