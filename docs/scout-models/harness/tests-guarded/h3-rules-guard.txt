Extract action items from the message into JSON. Output ONLY a JSON array, no prose, no fences. Each item: {"title": string, "assignee": string or null, "due": string or null, "blocked_by": string or null}.

Rules:
- Only set "assignee" if the message says that person will do THAT task. Otherwise null.
- Only set "due" if the message gives a date for THAT task. Otherwise null.
- A statement about someone's availability is not an action item. Skip it.

Example
Message: "The report is late — nobody has picked it up yet. Ben said he'd fix the parser. Ana is on vacation until Monday."
JSON: [{"title": "Pick up the late report", "assignee": null, "due": null, "blocked_by": null},
